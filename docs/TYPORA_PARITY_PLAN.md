# Typora 能力对标与实现计划

本文把“达到商业化软件水平”定义为产品能力和日常写作体验达到成熟桌面 Markdown
编辑器的水平，不包含付费、账号、授权、签名、自动更新、发布流水线或商业支持。

对标基线来自 Typora 官方支持文档，核对日期为 2026-08-27。Typora 文档中的
功能并不全部属于 Markdown 标准，因此本项目将能力分为三类：

- **必须对标**：高频写作、项目文档管理、图片资源、查找导航和可靠输出。
- **兼容对标**：Typora 常用扩展语法和安全的 HTML 子集。
- **明确不对标**：商业基础设施、云服务、移动端、全部历史导出格式和不安全嵌入。

## 结论

MDEditor 目前已经具备可靠的 Markdown 源码编辑器底座，但还没有达到 Typora
级别的完整写作体验。

已经达到或具有优势的部分包括：CommonMark/GFM 基础语法、源码与混合模式、
任务列表和基础表格交互、大纲、KaTeX/Mermaid 预览、多标签页、安全 HTML 导出、
系统打印/PDF、主题、快捷键，以及字节保真、原子保存、外部变更检测和崩溃恢复。

主要差距不是“再增加几个语法高亮”，而是以下四条完整工作流尚未闭环：

1. 像 Typora 一样在同一编辑面中完成即时预览和原地编辑。
2. 用格式化命令、完整表格操作、查找替换和写作辅助完成高频编辑。
3. 以文件夹为工作区管理文档、链接和图片资源。
4. 让扩展语法、图片、数学和图表在预览、HTML、图片和 PDF 中一致输出。

因此，旧计划中把“商业编辑器功能对等”列为非目标是不正确的。后续应继续排除
商业化基础设施，但把 Typora 级 Markdown 能力作为产品主线。

## 实现原则

### 1. Markdown 文本继续是唯一真实状态

即时预览不能引入第二份富文本状态。所有按钮、表格操作、任务复选框、图片插入
和格式化命令都必须生成可撤销的 CodeMirror transaction，并直接修改规范 Markdown
文本。保存、撤销、恢复和导出继续读取同一份文本。

### 2. 用“活动结构展开”实现 Typora 式编辑

不重写为独立 contenteditable 编辑器。在现有 CodeMirror/Lezer 架构上实现：

- 光标或选区所在的 Markdown 结构显示完整源码标记；
- 非活动结构隐藏可安全推导的分隔符并展示排版结果；
- 图片、任务、数学、图表、表格等块可点击进入源码编辑状态；
- decorations 只覆盖可视区域，异步部件可取消并独立失败；
- 模式切换不得改变文本、选区、撤销栈或 IME 组合输入。

这可以得到接近 Typora 的即时预览体验，同时保留项目已经验证过的源码安全模型。

### 3. 编辑与导出共享同一 Markdown 能力清单

在 `@mdeditor/markdown` 中新增版本化 `MarkdownProfile`，统一声明 CommonMark、GFM、
脚注、Front Matter、TOC、Alert、数学和图表规则。编辑器解析、即时预览和导出分别
实现同一组夹具，禁止出现“编辑器看得到、导出丢失”或相反的情况。

扩展语法默认选择与 Typora/GFM 兼容且可移植的写法。非标准功能必须可关闭，
关闭后源码仍原样保留。

### 4. 文件夹授权是新的桌面安全边界

打开文件夹后，Rust 端保存用户明确授权的根目录；列目录、搜索、监听、重命名、
移动和图片复制只能在授权根内进行。默认不跟随逃出根目录的符号链接，所有覆盖
操作都必须确认并采用原子写入。应为该边界新增 ADR 和路径穿越测试。

### 5. 先完成高频闭环，再追求格式数量

对标的优先顺序是：写作体验、文件/图片工作流、输出一致性、长尾格式。EPUB、
LaTeX、OpenOffice、云发布等格式不是当前商业级体验的必要条件；DOCX 通过可选
Pandoc 适配器实现即可，不把 Pandoc 打包成核心运行依赖。

## 分阶段方案

### M4：Typora 级单文档写作核心

目标是在不切换到独立预览窗的情况下，顺畅完成一篇包含常用扩展语法的文档。

1. 实现活动结构展开的 Live Preview，覆盖标题、强调、删除线、行内代码、链接、
   引用、列表、任务、表格、图片、代码块、数学和 Mermaid。
2. 建立统一的 Markdown transaction 命令层，支持标题、粗体、斜体、删除线、
   行内代码、链接、图片、引用、有序/无序/任务列表、代码块、数学块、表格和
   水平线；正确处理空选区、多选区、嵌套、Unicode 和重复执行。
3. 补齐脚注、YAML Front Matter、`[toc]`、GitHub Alert、`$...$` 与 `$$...$$`。
4. 完整表格操作：增删行列、列对齐、改变规模、移动行列；所有操作一次撤销。
5. 为查找/替换提供应用入口并覆盖大小写、整词、正则和替换全部。
6. 增加大纲过滤/折叠、字数/字符/行数/阅读时间和选区统计。
7. 增加 Focus、Typewriter 及 Markdown 自动配对/包围选区。

M4 完成条件：定义的单文档写作场景无需退回纯源码模式；所有功能保持源码可逆，
通过 IME、撤销重做、Unicode、1/10 MiB 性能和编辑/导出一致性回归。

### M5：文件夹、链接与图片工作流

目标是能够把一个真实文档仓库当作工作区长期使用。

1. 桌面端增加打开文件夹、授权根目录、递归文件枚举和文件监听；界面增加可虚拟
   滚动的文件树/文件列表。
2. 增加新建文件/文件夹、重命名、移动、复制、删除、在资源管理器中显示和复制
   路径；脏文件及外部变化必须有明确冲突处理。
3. 增加模糊快速打开和可取消的全局搜索，支持大小写、整词、正则、结果预览和
   跳转。Rust 端使用受限遍历和流式结果，忽略二进制及超限文件。
4. 支持内部标题、本地 Markdown 文件和外部 URL 的安全导航；重命名文件时提供
   可预览的链接更新，不静默改写整个仓库。
5. 支持剪贴板图片、拖放和文件选择；按工作区策略复制到资源目录，处理重名、
   相对路径、空格/括号转义和失败回滚。
6. 增加图片重命名、移动/复制、复制全部到目录和失效引用检查。删除图片必须经过
   引用扫描和确认。
7. 增加可配置自动保存。保存已有文件前重新校验磁盘指纹，冲突时暂停自动保存并
   提示；未命名文档继续只写恢复快照。

M5 完成条件：可以打开包含中文路径、嵌套目录和本地图片的仓库，完成检索、编辑、
资源导入、重命名、自动保存和恢复；路径逃逸、符号链接、外部修改和失败注入测试
不能造成越权或数据损坏。

### M6：输出一致性、主题与个人分发

目标是让编辑结果可以可靠交付，同时保持个人开源项目的轻量分发方式。

1. 重构统一渲染管线，使脚注、TOC、Alert、数学、Mermaid 和本地图片在即时预览、
   带样式 HTML、无样式 HTML、打印/PDF 中结果一致。
2. 增加图片导出，以及 PDF 纸张、方向、边距、页眉页脚和分页控制。优先复用系统
   打印；只有系统能力不足时才引入专用 PDF 生成器。
3. 提供可选 Pandoc 适配器输出 DOCX；检测外部 Pandoc，不存在时给出安装说明，
   不阻塞核心编辑器和安装包。
4. 增加系统拼写检查开关和语言选择。Windows 首先验证 WebView2/系统能力，只有
   不能满足需求时才评估内置词典。
5. 增加可安装主题。CSS 限定在文档表面，拒绝远程 `@import` 和越界资源；高级
   本地 CSS 作为明确标注的受信设置。
6. 安全渲染常用 inline/block HTML；继续禁止脚本、事件属性和任意 iframe。
7. 完成无障碍自动检查、Windows 键盘/高对比度/缩放复核。
8. 最后再按 `MANUAL_DISTRIBUTION.md` 生成无签名 Windows x64 安装包、校验和和
   说明，并人工上传到 Git 托管平台。

M6 完成条件：基准文档在编辑、HTML、图片和 PDF 中通过结构和视觉快照检查；
Windows 安装包可从版本化提交复现并通过干净环境冒烟测试。签名、自动更新和自动
发布不属于完成条件。

## 验收场景

商业级能力不以功能数量判断，而以端到端任务验收：

1. **长文写作**：中文 IME 输入、格式化、脚注、数学、图表、大纲导航、查找替换、
   字数统计和撤销重做连续工作，重启后恢复到同一内容。
2. **项目文档**：打开仓库、快速找文件、全局搜文本、跟随内部链接、修改多标签页，
   外部编辑冲突不会被覆盖。
3. **图片笔记**：直接粘贴和拖入多张图片，自动保存到相对资源目录；移动文档或
   图片时能发现并处理引用。
4. **技术文档输出**：表格、任务、脚注、Alert、KaTeX、Mermaid 和本地图片在 HTML
   与 PDF 中不丢失，链接和不可信 HTML 仍受安全策略约束。
5. **大文件与失败恢复**：1 MiB/10 MiB 文档的可见区编辑不明显退化；渲染器、图片
   复制、搜索、保存和导出失败不会破坏原文件或阻塞源码编辑。

## 明确延期

以下内容不影响 Typora 级 Markdown 产品能力的判断，继续延期：

- 付费、账号、许可证、遥测、增长和商业支持系统；
- 代码签名、公证、自动更新、发布通道和自动发布流水线；
- 实时协作、托管云同步、移动客户端和 AI 写作；
- 插件市场及执行任意第三方代码；
- 脚本、事件属性、无约束 iframe 等高风险 HTML；
- 对 Typora 每个历史特性、旧图表引擎和所有 Pandoc 格式做逐项复制。
